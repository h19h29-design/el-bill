# 개인 사용자 간편 입력 및 사용 안내 설계

## 배경

현재 앱은 한전 고지서 XLSX/CSV와 파워플래너 HTML `.xls` 파일을 브라우저에서
분석한다. 자동 인식에 실패하면 컬럼을 직접 매핑할 수 있지만, 파일 자체가 손상됐거나
지원하지 않는 형식이면 월별 값을 직접 입력할 방법이 없다. 한전 EDS는 고객 동의를
기반으로 한 서비스 사업자용 연계이므로 일반 개인 사용자가 API 키를 즉시 발급받는
것을 전제로 할 수 없다.

이번 개선은 공식 API나 계정 자동화를 흉내 내지 않고, 개인 사용자가 가진 자료를 가장
적은 조작으로 진단 데이터로 바꾸는 데 집중한다.

## 목표

- 고지서 입력 화면에서 파일 업로드, 표 붙여넣기, 직접 입력을 선택할 수 있다.
- 직접 입력은 최근 12개월을 빠르게 입력할 수 있고 36개월까지 확장할 수 있다.
- 모든 입력 경로는 같은 정규화, 검증, 미리보기, 적용 절차를 사용한다.
- 지원 브라우저에서는 사용자가 선택한 폴더에서 최신 지원 파일을 한 번에 찾을 수 있다.
- 별도 사용 안내 화면에서 처음부터 문서 생성까지 순서대로 설명한다.
- GPT 무료 서비스로 임의 형식 자료를 표준 CSV로 바꾸는 정확한 프롬프트를 제공한다.
- 입력 초안과 적용 데이터는 기존 정책대로 최대 24시간 후 삭제한다.
- 향후 공식 EDS 연계가 가능할 때 교체할 수 있는 Connector 인터페이스는 유지한다.

## 비목표

- 한전·파워플래너 계정 자동 로그인
- 웹 크롤링 또는 비공식 API 호출
- 일반 개인에게 EDS 키가 발급된 것처럼 동작하는 모의 자동연동
- 백그라운드 폴더 감시
- 이메일 계정 연결 및 첨부 자동 수집
- PDF·사진 OCR
- GPT API 직접 호출 또는 OpenAI API 키 사용
- 사용자 원본 파일의 NAS 저장

## 권장 사용자 흐름

1. 사용자는 대시보드에서 `전기요금 자동진단 시작`을 선택한다.
2. 고지서 입력 화면에서 다음 순서로 가장 쉬운 방법을 선택한다.
   - 파일 자동 인식
   - 표 복사·붙여넣기
   - 빠른 수기 입력
   - GPT로 표준 CSV 변환 후 업로드
3. 앱은 원본 적용 전에 인식 결과, 누락 항목, 중복 월, 연속 기간을 보여준다.
4. 사용자가 `이 데이터로 분석 시작`을 선택해야 기존 진단 데이터가 교체된다.
5. 자동진단, 요금제 비교, 피크관리, 문서 생성은 현재의 동일한 흐름을 사용한다.

## 고지서 입력 화면

고지서 입력 화면 상단에 다음 세 개의 탭을 둔다.

- `파일 업로드`
- `표 붙여넣기`
- `직접 입력`

탭 전환은 작성 중인 직접 입력 초안을 삭제하지 않는다. 각 탭은 독립된 입력 UI를
제공하지만 결과를 공통 `BillImportPreview`로 전달한다. 미리보기에서는 원본 출처,
행 수, 인식된 기간, 필수·선택 컬럼, 기간 문제와 적용 후 진단 가능 여부를 표시한다.

### 파일 업로드

현재 XLSX/CSV/파워플래너 HTML `.xls` 파서와 보안 제한을 그대로 유지한다.
자동 인식과 수동 컬럼 매핑도 유지한다. 화면에는 `다운로드 폴더에서 찾기`를 보조
버튼으로 추가한다.

### 다운로드 폴더에서 찾기

- `showDirectoryPicker` 지원 여부를 기능 탐지한다.
- 지원 브라우저에서 사용자가 버튼을 누른 경우에만 폴더 선택 권한을 요청한다.
- 선택한 폴더의 최상위 파일 중 지원 확장자와 매직 바이트 검사를 통과한 최신 파일
  하나만 미리보기로 연다.
- 폴더 핸들은 영구 저장하지 않으며 현재 페이지 세션에서만 사용한다.
- 자동 업로드, 하위 폴더 탐색, 백그라운드 감시는 하지 않는다.
- 미지원 브라우저에는 기능을 숨기지 않고 `Chrome 또는 Edge에서 사용할 수 있습니다`
  안내와 일반 파일 선택 버튼을 보여준다.

## 표 붙여넣기

사용자가 Excel, Numbers, Google Sheets 또는 파워플래너 표에서 복사한 텍스트를
붙여넣을 수 있는 입력 영역을 제공한다.

- 탭 구분 텍스트와 RFC 4180 형식 CSV를 지원한다.
- 첫 행을 헤더로 해석하고 기존 컬럼 별칭과 공통 매핑 엔진을 사용한다.
- 헤더가 없으면 사용자가 컬럼 순서를 선택해야 한다.
- 여러 셀을 직접 입력 표의 첫 셀에 붙여넣는 동작도 같은 파서를 사용한다.
- 붙여넣기만으로 현재 진단 데이터를 변경하지 않는다.
- 최대 36개월, 최대 36행만 허용한다.

## 빠른 수기 입력

### 기본 모드

상단 제어는 다음과 같다.

- 마지막 청구월: 기본값은 현재 연월이며 사용자가 변경할 수 있다.
- 생성 기간: `12개월` 또는 `36개월`
- `입력행 생성`
- `전체 초기화`

기본 표에는 다음 컬럼만 표시한다.

| 컬럼 | 필수 | 동작 |
| --- | --- | --- |
| 연월 | 예 | `YYYY-MM`, 중복 불가 |
| 사용량(kWh) | 예 | 0보다 큰 숫자 |
| 총 전기요금(원) | 예 | 0보다 큰 숫자 |
| 최대수요전력(kW) | 아니요 | 입력 시 0보다 큰 숫자 |
| 상태 | - | 정상 또는 행별 보완 안내 |

`입력행 생성`은 마지막 청구월부터 과거 방향으로 중복 없는 연월을 만든다. 기존 입력값이
있으면 덮어쓰기 전에 확인한다.

### 상세 모드

`상세 항목 펼치기`를 선택하면 다음 선택 컬럼을 편집할 수 있다.

- 요금적용전력
- 기본요금
- 전력량요금
- 역률요금
- 기후환경요금
- 연료비조정액
- 부가세
- 전력산업기반기금
- 메모

요금적용전력에는 `모든 월에 동일 적용` 동작을 제공한다. 선택 컬럼의 빈 값은 0으로
관측한 것으로 취급하지 않고 `미제공`으로 남긴다.

### 입력 편의

- `Tab`, `Shift+Tab`, `Enter`, 방향키로 인접 셀을 이동한다.
- 여러 셀을 붙여넣으면 시작 셀부터 행과 열에 맞춰 채운다.
- 화면에는 천 단위 구분기호를 표시하되 저장 값은 숫자로 정규화한다.
- `원`, `kWh`, `kW`, 공백, 쉼표가 포함된 붙여넣기 값을 정리한다.
- 모바일 숫자 입력은 숫자 키패드를 요청한다.
- 행 추가와 행 삭제를 제공하되 최대 36행을 넘지 않는다.
- 오류가 있는 행만 강조하고 첫 오류로 이동하는 버튼을 제공한다.
- 적용 전에는 기존 정상 진단 데이터를 변경하지 않는다.

## 직접 입력 초안

부분 입력 행은 진단 데이터와 분리된 `BillEntryDraft`로 저장한다.

```ts
interface BillEntryDraft {
  version: 1
  sessionId: string
  revision: number
  createdAt: string
  expiresAt: string
  rows: ManualBillDraftRow[]
}

interface ManualBillDraftRow {
  id: string
  yearMonth: string
  usageKwh: string
  totalBillWon: string
  maxDemandKw: string
  appliedPowerKw: string
  baseChargeWon: string
  energyChargeWon: string
  powerFactorChargeWon: string
  climateChargeWon: string
  fuelAdjustmentWon: string
  vatWon: string
  fundWon: string
  note: string
}
```

- 초안은 브라우저 로컬 저장소에 최대 36행만 저장한다.
- 저장 키는 현재 앱 세션에 결합된
  `el-bill:bill-entry-draft:v1:<encoded-session-id>`를 사용한다.
- 초안 쓰기는 기존 `el-bill:storage-mutation` Web Lock 안에서 revision을 비교한 뒤
  수행한다. Web Locks API가 없는 브라우저에는 기존과 같은 한 탭 사용 안내를 적용한다.
- `0 < expiresAt - createdAt <= 24시간`을 강제한다.
- 내용을 수정해도 최초 `createdAt`과 `expiresAt`은 연장하지 않는다.
- 만료, 시연 샘플 초기화, 정상 적용 완료 시 초안을 물리적으로 삭제한다.
- 초안은 자동진단, 추천, 문서 생성에 사용하지 않는다.
- 저장 실패 시 현재 화면 입력은 유지하고 한국어 안내를 표시한다.

## 공통 정규화와 출처

모든 입력은 `RawBillInputRow[]`에서 `MonthlyBill[]`로 변환되는 한 경로를 사용한다.
파일 파서가 자동으로 만든 행도 적용 직전에 같은 도메인 검증을 다시 거친다.

`BillDataOrigin`은 다음으로 확장한다.

```ts
type BillDataOrigin = 'sample' | 'uploaded' | 'pasted' | 'manual'
```

- 파일 및 폴더: `uploaded`
- 표 붙여넣기: `pasted`
- 직접 입력: `manual`
- GPT가 만든 CSV: 파일로 들어오므로 `uploaded`

필수값은 연도, 월, 사용량, 총 전기요금이다. 연월은 유효한 달이어야 하고 사용량과
총요금은 0보다 커야 한다. 같은 연월이 둘 이상 있으면 어느 행도 임의 채택하지 않고
전체 적용을 막는다. 기존 요금제와 정확히 일치하는 요금표가 없으면 미리보기와 초안
저장은 허용하지만 분석 적용은 막는다.

수기·붙여넣기 출처는 데이터 신뢰도 설명에 표시한다. 36개월과 최대수요전력이 있다고
해서 수기 입력 자료를 한전 원본과 동일하다고 표현하지 않는다.

## 사용 안내 화면

사이드바에 `사용 안내`를 추가하고 각 입력 화면의 도움말 링크가 해당 섹션으로 이동하게
한다. 사용 안내는 다음 순서로 구성한다.

1. 가장 쉬운 방법: 파일을 그대로 올리기
2. 자동 인식이 안 될 때: 표 복사·붙여넣기
3. 파일이 없을 때: 최근 12개월 직접 입력
4. 자료 형식이 복잡할 때: GPT로 CSV 변환
5. 파워플래너에서 자료 내려받기
6. 자동진단 결과 확인
7. 피크관리 방안 확인
8. 변경신청 문서 생성
9. 데이터 보안과 24시간 삭제
10. 요금제 변경은 원칙적으로 1년에 한 번만 가능하다는 신중 검토 안내

EDS 섹션은 `개인 사용자는 공식 API 자동연동을 기본 제공받지 않으며, 기관 또는
서비스 사업자 승인이 있을 때만 연동할 수 있습니다`라고 표시한다. 발급되지 않은 키나
연동 완료 상태를 시뮬레이션하지 않는다.

## GPT 변환 안내

안내 화면에 다음을 제공한다.

- `표준 CSV 양식 다운로드`
- `GPT 변환 프롬프트 복사`
- 변환 결과 업로드로 이동
- 개인정보 보호 경고

GPT에 업로드하기 전에 학교명, 고객번호, 주소, 담당자 이름·전화번호, 계좌나 납부정보를
삭제하도록 안내한다. 외부 AI 서비스에 업로드한 파일에는 이 앱의 24시간 삭제 정책이
적용되지 않는다고 명시한다.

### 제공 프롬프트

```text
첨부한 전기요금 또는 전력사용 자료를 아래 규칙에 맞는 UTF-8 CSV 파일로 변환해 주세요.
이 작업은 데이터 형식 변환만 수행합니다. 원본에 없는 값은 계산하거나 추측하지 마세요.

[출력 파일]
- 파일명: el-bill-import.csv
- 한 행은 한 청구월만 나타냅니다.
- 첫 행은 아래 컬럼명을 정확히 사용합니다.

연도,월,사용량(kWh),총 전기요금(원),요금적용전력(kW),최대수요전력(kW),기본요금(원),전력량요금(원),역률요금(원),기후환경요금(원),연료비조정액(원),부가세(원),전력산업기반기금(원),메모

[필수 규칙]
1. 연도, 월, 사용량(kWh), 총 전기요금(원)은 반드시 원본에서 찾아 입력합니다.
2. 필수값을 원본에서 확인할 수 없는 행은 CSV에 넣지 말고 검토사항에 기록합니다.
3. 선택 항목이 원본에 없으면 0으로 만들지 말고 빈칸으로 둡니다.
4. 숫자에는 쉼표, 원, kWh, kW, 공백을 넣지 않습니다.
5. 음수로 명시된 연료비조정액은 음수 부호를 유지합니다.
6. 같은 연도와 월이 중복되면 하나를 임의 선택하지 말고 검토사항에 기록합니다.
7. 합계, 소계, 누계, 평균 행은 월별 데이터로 변환하지 않습니다.
8. 수식, 임의 보정값, 예상값을 만들지 않습니다.
9. 날짜는 연도와 월로 분리하고 월은 1~12 숫자로 출력합니다.
10. 학교명, 고객번호, 주소, 담당자 연락처, 계좌·납부정보는 CSV에 포함하지 않습니다.

[응답]
1. 먼저 다운로드 가능한 el-bill-import.csv 파일을 제공합니다.
2. 그 다음 짧은 검토사항을 작성합니다.
3. 검토사항에는 변환 행 수, 인식한 기간, 누락 필수값, 중복 월, 판독이 불확실한 항목만 적습니다.
4. 문제가 없으면 "검토사항 없음"이라고 적습니다.
```

GPT 결과는 신뢰된 원본으로 취급하지 않는다. 사용자가 앱에서 미리보기와 누락·중복
검사를 확인한 뒤에만 분석에 적용할 수 있다.

## EDS 연결 준비

현재 릴리스에는 NAS API 서버를 추가하지 않는다. 공개 도메인에 인증되지 않은 개인
데이터 API를 만드는 것은 실제 EDS 키가 없는 상태에서 가치보다 공격면이 크기 때문이다.

프런트엔드에는 다음 인터페이스만 정의한다.

```ts
type ConnectorStatus =
  | { state: 'unavailable'; reason: string }
  | { state: 'ready'; provider: string }
  | { state: 'error'; message: string }

interface BillDataConnector {
  id: string
  label: string
  getStatus(): Promise<ConnectorStatus>
  fetchBills(customerReference: string): Promise<MonthlyBill[]>
}
```

현재 등록되는 구현은 `ManualImportConnector`뿐이다. EDS 메뉴나 API 키 입력 UI는
노출하지 않는다. 공식 승인과 명세가 확보된 후 별도 보안 설계와 백엔드 인증을 거쳐
`KepcoEdsConnector`를 추가한다.

## 오류 처리

- 자동 인식 실패는 직접 입력과 GPT 변환 안내로 연결한다.
- 붙여넣기 파싱 실패는 원문을 지우지 않고 문제 위치와 지원 예시를 보여준다.
- 직접 입력 오류는 행과 셀에 연결하고 정상 행까지 함께 삭제하지 않는다.
- 폴더 권한 거절은 오류로 취급하지 않고 일반 파일 선택으로 돌아간다.
- 초안 저장 실패는 적용 데이터와 출처를 변경하지 않는다.
- 공통 적용 저장 실패는 직전 정상 스냅샷을 유지한다.
- 예상하지 못한 화면 오류는 기존 ViewErrorBoundary로 격리한다.

## 접근성과 반응형

- 탭은 `tablist`, `tab`, `tabpanel` 의미와 키보드 이동을 제공한다.
- 오류 문구는 해당 입력과 `aria-describedby`로 연결한다.
- 상태 변경은 `role=status`로 알린다.
- 직접 입력 표는 데스크톱에서 고정 헤더와 안정된 컬럼 폭을 사용한다.
- 모바일에서는 기본 컬럼을 우선 표시하고 상세 컬럼은 가로 스크롤로 접근한다.
- 표 앞에 `표를 좌우로 밀어 상세 항목을 확인하세요` 안내를 표시한다.
- 아이콘 버튼에는 접근 가능한 이름과 툴팁을 제공한다.

## 테스트

### 단위 테스트

- 12개월과 36개월 연월 역순 생성
- 단위·쉼표가 포함된 숫자 정규화
- 탭 구분 표와 CSV 붙여넣기
- 헤더 없는 표의 수동 매핑
- 필수값 누락, 잘못된 월, 음수, 0, 중복 월 거부
- 선택값 빈칸이 관측값 0으로 바뀌지 않음
- 직접 입력 초안 저장, 복원, 적용 후 삭제, 24시간 만료 삭제
- 폴더 API 미지원과 권한 거절 대체 흐름
- 출처별 표시와 진단 신뢰도 안내
- GPT 프롬프트의 정확한 컬럼명과 개인정보 경고

### 컴포넌트 테스트

- 세 입력 탭의 키보드 전환
- 최근 12개월 생성과 상세 항목 토글
- 다중 셀 붙여넣기와 전체 요금적용전력 채우기
- 오류 행 이동과 정상 적용
- 사용 안내의 프롬프트 복사와 CSV 양식 다운로드
- 도움말 링크의 해당 섹션 이동

### E2E

- 파일 업로드 기존 흐름 회귀 테스트
- 붙여넣기에서 자동진단까지
- 직접 입력 12개월에서 자동진단까지
- 새로고침 후 초안 복원
- GPT 표준 CSV 업로드
- 모바일 입력과 사용 안내
- 24시간 만료 후 초안과 적용 데이터 삭제

최종 검증은 `npm run typecheck`, `npm run lint`, `npm run test`,
`npm run build`, `npm run test:e2e`를 모두 통과해야 한다.

## 완료 조건

- 자동 인식 실패 자료도 표 붙여넣기나 직접 입력으로 진단할 수 있다.
- 처음 사용하는 개인 사용자가 사용 안내만 따라 최근 12개월 진단을 완료할 수 있다.
- 직접 입력 중 페이지를 새로고침해도 만료 전 초안이 복원된다.
- GPT 변환 프롬프트와 표준 CSV 양식이 앱에서 제공된다.
- 외부 AI 업로드와 앱의 24시간 삭제 정책 차이가 명확히 표시된다.
- 실제 EDS 승인이 없는 상태를 자동연동 완료로 오해하게 만드는 화면이 없다.
- 기존 자동진단, 피크관리, 문서 생성 기능이 삭제되거나 약화되지 않는다.
