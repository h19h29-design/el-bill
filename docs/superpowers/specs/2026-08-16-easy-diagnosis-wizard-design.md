# 쉬운 진단 마법사 설계

## 목적

학교 전기요금 업무를 처음 맡은 사용자가 기존의 전문가용 메뉴를 이해하지 않아도
연속 12개월 고지서 PDF 또는 12개월 요금 정리표만으로 요금제 유지·변경 판단까지
완료할 수 있게 한다.

새 흐름은 초보자용 화면을 별도로 제공한다. 기존 `자동진단`, `고지서 입력`,
`요금제 비교`, `피크관리`, `문서생성`, `설정` 화면은 삭제하거나 단순화하지 않는다.
새 화면은 검증된 파서, 계산 엔진, 저장소와 24시간 TTL 같은 내부 기능만 선별해
사용하고 기존의 복잡한 화면 컴포넌트는 포함하지 않는다.

## 용어

- `12개월 고지서 PDF`: 연속 12개월의 한전 전기요금 고지서 PDF 파일 묶음 또는
  여러 청구월이 들어 있는 PDF다.
- `12개월 요금 정리표`: 학교가 연도, 월, 사용량, 총 전기요금을 12개월 이상
  정리한 엑셀 또는 CSV 파일이다. 한전의 요금 단가표를 뜻하지 않는다.
- `쉬운 진단`: 이 문서에서 새로 추가하는 초보자용 단계별 화면이다.
- `전문가용 화면`: 현재 사이드바에서 제공하는 기존 메뉴 화면이다.

## 핵심 원칙

1. 연속 12개월이 없으면 변경 또는 유지 결론을 내리지 않는다.
2. 시연 샘플은 쉬운 진단의 실제 결과로 사용하지 않는다.
3. 한 화면에서는 한 가지 결정이나 작업만 요구한다.
4. 결론은 `변경하세요`, `유지하세요`, `지금은 변경하지 마세요` 중 하나로 시작한다.
5. 결론 바로 아래에 금액, 이유, 주의사항을 평이한 문장으로 표시한다.
6. 기존 전문가용 화면과 기능은 유지한다.
7. 입력 자료는 브라우저에서만 처리하고 기존 정책대로 최대 24시간 후 삭제한다.
8. 공식 청구액 계산기가 아니라 학교 내부 진단용 추정이라는 안내를 유지한다.
9. 요금제 변경은 원칙적으로 1년에 한 번만 가능하므로 신중히 검토해야 한다는
   안내를 결과와 문서 연결 지점에 표시한다.

## 정보 구조

### 진입점

- `ViewKey`에 `easyDiagnosis`를 추가한다.
- 사이드바에서 `대시보드` 다음에 `쉬운 진단` 항목을 추가한다.
- 대시보드의 가장 큰 CTA 문구를 `쉬운 진단 시작`으로 바꾸고
  `easyDiagnosis`로 이동시킨다.
- 기존 `자동진단` 메뉴는 유지하며 이름과 기능을 바꾸지 않는다.

### 단계 1: 준비물 선택

다음 네 가지 입력 경로를 제공한다.

1. `12개월 고지서 PDF`
2. `12개월 요금 정리표(엑셀·CSV)`
3. `표 붙여넣기`
4. `직접 입력`

첫 번째와 두 번째를 주요 선택으로 표시한다. 붙여넣기와 직접 입력은 파일이 없거나
자동 인식이 실패했을 때 사용할 보조 경로로 표시한다. 모든 선택지에
`연속 12개월 자료 필요`를 표시한다.

스캔 PDF나 사진 자료만 있는 사용자를 위해 `무료 AI로 표 만들기` 보조 동작을
제공한다. 이 동작은 기존 표준 CSV 변환 프롬프트, CSV 양식, 개인정보 제거 경고를
사용하며 외부 AI로 파일을 자동 전송하지 않는다.

### 단계 2: 자료 넣기

선택한 입력 경로에 필요한 조작만 표시한다.

- PDF: 여러 파일을 한 번에 선택할 수 있고 파일명과 인식 진행 상태를 표시한다.
- 엑셀·CSV: 파일 하나를 선택하고 시트와 컬럼을 자동 인식한다.
- 붙여넣기: 스프레드시트 셀 범위를 그대로 붙여넣을 수 있다.
- 직접 입력: 최근 12개월 행을 기본으로 만들고 사용량과 총요금을 붙여넣거나
  입력할 수 있다.

학교정보, 고급 요금표 설정, 현재 적용 데이터 전체 표는 이 단계에서 표시하지
않는다. 상단에는 브라우저 로컬 처리와 24시간 자동 삭제 안내를 유지한다.

### 단계 3: 인식 결과 확인

긴 원본 데이터 표 대신 다음 요약을 먼저 표시한다.

- 인식한 기간과 `12/12개월` 상태
- 누락 월과 중복 월
- 필수 컬럼 `연도`, `월`, `사용량`, `총 전기요금`
- 선택 컬럼 `요금적용전력`, `최대수요전력`, 요금 구성 항목
- 자동 매핑 신뢰도
- 최근 12개월의 월별 사용량·총요금 간단 미리보기

연속 12개월, 필수 컬럼, 유효한 양수 값 조건을 모두 만족해야 다음 단계로 이동할
수 있다. 조건을 만족하지 못하면 오류 코드 대신 수정할 월과 컬럼을 문장으로
안내한다. 자동 매핑 수정, 입력 방식 변경, 무료 AI 변환으로 이동할 수 있다.

### 단계 4: 계약정보 확인

다음 값만 확인한다.

- 계약종별
- 수전전압
- 현재 요금제
- 요금적용전력

PDF 또는 정리표에서 인식한 값은 미리 채운다. 인식하지 못한 값은 현재 학교용
요금제 목록에서 선택하게 한다. 요금적용전력은 최근 고지서에서 인식한 값을
우선 사용하고 없으면 사용자가 직접 입력하게 한다. 각 입력에는 고지서에서 확인할
위치를 짧게 표시한다.

현재 계약종별·수전전압·현재 요금제와 정확히 일치하는 유효한 요금제가 하나여야
분석을 시작할 수 있다. 일치하지 않으면 쉬운 진단에서는 결론을 만들지 않고
선택값 수정 또는 전문가용 `설정` 화면으로 이동하게 한다.

### 단계 5: 진단 결과

결론 영역을 첫 화면의 가장 큰 시각 요소로 표시한다.

- 변경 추천: `[추천 요금제명]으로 변경하세요`
- 유지 추천: `현재 [현재 요금제명]을 유지하세요`
- 분석 보류: `지금은 변경하지 마세요`

결론 아래에는 다음 정보를 이 순서로 표시한다.

1. 최근 연속 12개월 기준 예상 절감액 또는 증가액
2. 현재안과 추천안의 12개월 예상액
3. 결론을 만든 핵심 이유 최대 3개
4. 기본요금, 전력량요금, 부가요금 중 가장 큰 영향 항목
5. 계산 신뢰도와 확인하지 못한 데이터
6. 피크 시나리오 사용 여부와 가정
7. 공식 청구액이 아닌 내부 진단용 추정 안내
8. 요금제 변경 후 원칙적으로 1년간 재변경 제한 안내

TOP 3 후보, 36개월 영향, 계산 근거 분해는 `상세 결과 보기`로 접어 둔다.
36개월 자료는 필수 조건이 아니며 없을 때는 장기 추세를 확인하지 못했다는
주의사항만 표시한다. 파워플래너 자료도 필수 조건이 아니며 결과 이후
`피크관리 자세히 보기`에서 선택적으로 보강한다.

결과의 다음 행동은 판단에 따라 다르게 제공한다.

- 변경 추천: `피크관리 확인`과 `변경신청 패키지 만들기`
- 유지 추천: `상세 비교 보기`와 `새 자료로 다시 진단`
- 분석 보류: 부족한 자료를 보완하는 단계로 돌아가는 버튼

## 컴포넌트와 책임

- `EasyDiagnosisWizard.tsx`: 단계 상태, 이전·다음 이동, 새로 시작, 최종 적용을
  조정한다.
- `EasyDiagnosisSourceStep.tsx`: 입력 경로 선택과 12개월 필수 안내를 담당한다.
- `EasyDiagnosisImportStep.tsx`: 선택한 경로에 맞는 파일·붙여넣기·직접 입력만
  표시하고 `BillInputCandidate`를 만든다.
- `EasyDiagnosisReviewStep.tsx`: 기간 연속성, 필수 컬럼, 중복과 누락을 요약한다.
- `EasyDiagnosisProfileStep.tsx`: 최소 계약정보를 확인하고 유효한 현재 요금제를
  찾는다.
- `EasyDiagnosisResultStep.tsx`: 명확한 결론, 이유, 주의사항과 다음 행동을
  표시한다.
- `easyDiagnosis.ts`: 단계 전환 조건, 후보 자료 검증, 결론 문구와 결과 요약을
  순수 함수로 제공한다.

기존 `BillUpload`, `AutoDiagnosis`, `RatePlanSettings` 컴포넌트를 쉬운 진단 안에
렌더링하지 않는다. 필요한 파싱 코드가 화면 컴포넌트에 묶여 있으면 동작을 바꾸지
않는 범위에서 `src/lib`의 순수 함수로 분리해 두 화면에서 공유한다.

## 데이터 흐름과 저장

1. 단계 2에서 브라우저 로컬 파서가 파일 또는 입력을 `BillInputCandidate`로 만든다.
2. 단계 3에서 연속 12개월과 필수 필드를 검증한다.
3. 단계 4에서 계약정보와 현재 요금제 일치 여부를 검증한다.
4. `분석 시작`을 누르면 고지서, 계약정보, 고지서 출처를 하나의 새 저장소
   스냅샷으로 원자적으로 저장한다.
5. 저장 성공 후 기존 `buildAutoDiagnosis` 계산 엔진으로 결과를 계산한다.
6. 저장 또는 검증 실패 시 현재 단계와 사용자의 입력을 유지하고 이동하지 않는다.

파일 객체 자체는 저장하지 않는다. 적용한 정규화 데이터만 기존 세션 스냅샷에
저장한다. 세션 생성 시각과 만료 시각은 기존 최대 24시간 정책을 그대로 사용하며
일반 편집으로 연장하지 않는다.

## 판단 규칙

- 연속 12개월과 정확히 일치하는 현재 요금제가 없으면 결과는 분석 보류다.
- `buildAutoDiagnosis`가 `변경 추천`을 반환하면 `변경하세요` 문구를 사용한다.
- `buildAutoDiagnosis`가 `유지 추천`을 반환하면 `유지하세요` 문구를 사용한다.
- `buildAutoDiagnosis`가 `추가 검토 필요`를 반환하면 `지금은 변경하지 마세요`
  문구를 사용한다.
- 시연 샘플 출처인 경우 결과를 표시하지 않고 실제 자료 입력 단계로 안내한다.
- 피크 자료가 없으면 피크를 반영하지 않은 12개월 고지서 기준 판단임을 표시한다.
- 피크 자료가 있으면 기본 판단과 피크 가정 결과를 구분해 표시한다.

## 오류 및 복구

- 12개월 미만: 빠진 청구월을 표시하고 다음 단계로 이동하지 않는다.
- 월 중복: 중복된 청구월을 표시하고 수정 전까지 이동하지 않는다.
- 필수 컬럼 누락: 자동 매핑 수정 또는 직접 입력으로 이동시킨다.
- 스캔 PDF: 문자 인식 실패를 설명하고 무료 AI 변환 또는 직접 입력을 제안한다.
- 계약정보 불일치: 학교용 후보 선택지를 제공하고 결론 생성을 보류한다.
- 저장 실패: 현재 입력과 단계를 유지하고 다시 시도 버튼을 제공한다.
- 예상하지 못한 파서 오류: 파일을 외부로 보내지 않고 입력 방식 변경을 제안한다.

## 접근성과 반응형

- 단계 표시에는 현재 단계와 완료 단계를 텍스트와 `aria-current`로 구분한다.
- 모든 파일 입력, 선택, 이전·다음 버튼은 키보드로 사용할 수 있어야 한다.
- 비활성 다음 버튼 옆에 충족하지 못한 조건을 텍스트로 표시한다.
- 모바일에서는 사이드바의 기존 반응형 규칙을 유지하고 단계 표시는 가로 스크롤
  대신 현재 단계 중심의 세로 요약으로 바꾼다.
- 결론과 주요 금액은 360px 너비에서도 잘리거나 다른 요소와 겹치지 않아야 한다.

## 테스트

### 단위 테스트

- 연속 12개월일 때만 인식 확인 단계를 통과한다.
- 11개월, 누락 월, 중복 월, 필수 컬럼 누락을 각각 차단한다.
- 변경 추천, 유지 추천, 추가 검토 필요를 세 가지 사용자 문구로 변환한다.
- 시연 샘플은 쉬운 진단 결과로 사용할 수 없다.
- 저장 실패 시 단계와 후보 입력을 유지한다.

### 컴포넌트 테스트

- 입력 경로 선택에 따라 관련 입력만 표시한다.
- 이전·다음과 새로 시작이 올바른 단계로 이동한다.
- 계약정보가 정확히 일치하지 않으면 분석 버튼을 비활성화한다.
- 결과의 이유, 주의사항, 1년 재변경 제한 안내를 표시한다.
- 상세 비교는 기본적으로 접혀 있고 사용자 동작으로 열린다.

### E2E 및 회귀 테스트

- PDF 12개월 → 인식 확인 → 계약 확인 → 변경 또는 유지 결론
- 엑셀·CSV 12개월 → 인식 확인 → 계약 확인 → 결론
- 붙여넣기와 직접 입력 12개월 → 결론
- 11개월 → 누락 월 안내와 진행 차단
- 쉬운 진단 완료 후 기존 자동진단·피크관리·문서생성에서 같은 적용 자료 확인
- 기존 전문가용 메뉴의 현재 주요 시나리오 회귀 테스트
- 데스크톱과 모바일에서 겹침, 잘림, 가로 넘침과 실제 버튼 동작 확인
- `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`,
  `npm run test:e2e` 통과

## 제외 범위

- 한전 자동 로그인, 크롤링, 비공식 API 호출
- 한전 공식 청구액 확정 또는 계약 변경 자동 제출

## 완료 조건

- 대시보드 CTA와 새 사이드바 항목에서 쉬운 진단을 시작할 수 있다.
- 사용자는 기존 메뉴를 열지 않고 다섯 단계만 따라 실제 자료 기반 결과를 얻는다.
- 연속 12개월 미만 자료로 변경·유지 결론을 만들 수 없다.
- 결과 첫 문장이 `변경하세요`, `유지하세요`, `지금은 변경하지 마세요` 중 하나다.
- 결과에 금액, 이유, 주의사항, 신뢰도와 1년 재변경 제한 안내가 보인다.
- 기존 전문가용 탭과 24시간 TTL 정책이 유지된다.
- 정적 검사, 단위·컴포넌트·E2E 테스트와 프로덕션 빌드가 통과한다.
